# Происхождение скриншота

`docs/images/report.png` - снимок реального HTML-отчёта, созданного установленным
wheel-пакетом по синтетическому логу `tests/sample/nginx-access-ui.log-20170629`.
Отчёт открыт в Chromium через Playwright при выключенной сети. Проверены две
строки результата и сортировка столбца количества запросов.

Анализатор создаёт HTML и локальный JavaScript. Браузер строит таблицу из данных
внутри HTML, сервер для просмотра не нужен. Изображение в README не участвует
в работе анализатора и не является макетом будущего интерфейса.
